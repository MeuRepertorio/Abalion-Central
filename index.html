PROTOCOLO DE EXECUÇÃO

Da central para o site.

  1. 01Selecione um ou mais projetos e escreva o que vai ser publicado.
  2. 02O Abalion prepara uma solicitação autenticada. Você confirma no GitHub, sem copiar códigos.
  3. 03O GitHub Actions cria os arquivos reais e registra a alteração no histórico.
  4. 04O GitHub Pages atualiza os sites. A nova aba aparece no projeto escolhido.
Publicação real: após enviar, confirme a issue na sua conta do GitHub. A automação registrará sucesso ou falha no histórico.

DUAS FUNÇÕES DIFERENTES. O observatório consulta dados públicos do GitHub. Para modificar o conteúdo dos sites, vá em Publicar nos projetos: a ação precisa ser confirmada pela sua conta do GitHub e executada por uma automação configurada com permissões restritas.
PRIVACIDADE E LIMITES

Projetos privados não são consultados. A API pública pode limitar consultas ou ficar indisponível. Nesse caso, os links e informações locais continuam funcionando. Nunca coloque tokens pessoais em sites públicos.
